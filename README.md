# Smart Guide (Graduation Project)
------------------------------------------------------------------
Smart Guide is an **AR indoor navigation / wayfinding app** built with **Unity + AR Foundation + Firebase**.  
It uses **QR-based localization (anchors)** to estimate the user’s position indoors, then renders **AR guidance overlays** to navigate toward **Points of Interest (POIs)**.  
Includes an **Admin POI management system** and **offline-ready support** for core navigation data.

## Key Features
- QR-based indoor localization (anchors)
- AR guidance overlays for navigation
- Offline-ready navigation data (maps/POIs)
- Admin system to manage POIs (create/update/delete)
- Firebase Auth roles (Admin/User)

## Tech Stack
- Unity + AR Foundation
- Firebase (Firestore, Auth)
- QR positioning / anchors
- Offline caching (maps + POIs)
